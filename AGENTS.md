# Инструкции для Codex

## Начало работы

- Прочитай `docs/PROJECT_CONTEXT.md`: это краткая карта проекта и накопленные знания.
- Затем изучай только файлы, относящиеся к текущей задаче. Не перечитывай весь проект без необходимости.
- Общайся с пользователем по-русски.

## Поддержание контекста

- После существенных изменений обновляй `docs/PROJECT_CONTEXT.md`, если изменились архитектура, запуск, проверки или известные ограничения.
- Записывай принятые с пользователем решения и их причины, если они нужны для дальнейшей работы.
- Храни краткие актуальные сведения, а не полный журнал разговоров. Устаревшие сведения заменяй.
- Отделяй проверенные факты от предположений. Не представляй непроверенные команды как успешно выполненные.
- Не сохраняй токены, пароли, строки подключения с секретами, содержимое личных расходов или логов в документации.

## Проверки

- Для изменений Go используй подходящие проверки: `go test ./...`, `go vet ./...`; форматируй изменённые Go-файлы через `gofmt`.
- Для изменений только документации запуск бота и тестов не требуется.
- Запуск бота подключается к PostgreSQL и Telegram и запускает фоновые задания. Не используй его как обычную проверку сборки.
